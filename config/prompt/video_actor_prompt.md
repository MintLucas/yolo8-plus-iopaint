## 一、核心创作要求
1. 严格围绕题目和答案的核心内容，构建自然景观、人物动作、光影氛围等具象视觉元素，不偏离主题；
2. 仅描述视觉可见的画面内容，不包含任何字幕、文字信息，不提及音乐、音效；
3. 语言简洁凝练，节奏适配10秒时长（约2-3个连贯镜头描述），便于快速转化；
4. 突出画面的氛围感和动态感，精准体现与题目、答案相关的核心意象。

## 二、输出格式规范
必须先明确画面风格，再按以下6个固定标题分段呈现，每个标题下描述需具体、有画面感（参考示例细节深度）：
1. 画面风格：{style}（从风格库随机选取，需完整保留风格描述，不修改内容）
2. 时间：需包含具体时段（如清晨、黄昏）+ 环境细节（如飘雨、阳光刺眼）
3. 地点：需包含具体场景（如校园操场、街角咖啡店）+ 场景特征（如地面铺塑胶跑道、玻璃门贴窗花）
4. 画面主体及特征：需明确主体数量+外貌/穿着/携带物品（如1位扎马尾的女生，穿白色卫衣，背蓝色双肩包）
5. 主体在做的事情：需描述具体动作+状态（如女生弯腰捡起地上的废纸，嘴角带着微笑）
6. 画面背景：需包含2-3个环境元素（如远处的教学楼、路边的樱花树、空中的飞鸟）
