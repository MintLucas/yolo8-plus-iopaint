<内容生成要求>
1、优先解析原博文核心场景
1.1 提取原博文的“主体（如美食、旅行目的地）+ 核心行为（如品尝美食、打卡拍照）+ 情感基调（如可爱、治愈）”，形成3要素总结，确保与具体场景（如美食体验、旅行打卡）强绑定。
1.2 若原博文含#带娃随手拍##旅行见山河##吃吃喝喝的日常#等场景类话题标签，需将其作为核心场景判断的首要依据，优先级高于博主领域标签。
1.3 明确“博主领域”与“博文内容”的边界
1.3.1 仅当原博文文本、图片或视频中，明确包含博主领域相关专业内容（如健康医疗领域的“疾病解答”“养生技巧”、数码领域的“产品评测”）时，才可关联领域标签。
1.3.2 若原博文是博主的非领域日常内容（如健康医疗博主记录带娃、数码博主分享美食），需完全以“日常场景”为核心生成文案，不强行套用博主领域标签。

2、学习历史转发文案及风格博文特征
从如下几个维度学习：
2.1 语言风格：先匹配原博文核心场景（如带娃场景用“软萌”“小调皮”等词汇，旅行场景用“治愈”“探索”等词汇）。再结合风格示例博文，分别总结“总结型”、“引导型”、“气氛型”这三种风格的语气、句式，语言特征。
2.2 结构与句式：学习历史转发博文常用的句式结构、常用短句结构、特定表情符号。
2.3 情感共鸣：分析历史转发博文的情感倾向，是否具有感性或理性的倾向，如何通过情感化的语言引发粉丝共鸣和情感连接，同时不偏离原博文情感方向。
3、图片，视频理解
3.1 图片理解：分析原博文图片的主体内容（如婴幼儿吃手画面、旅行风景）、视觉特征（如暖色调、生活化场景）、情绪氛围（如温馨、欢乐），确保文案能呼应图片信息。
3.2 视频理解：解析视频的关键画面、故事线（如记录亲子互动、旅行过程）、核心情绪，文案需提炼视频中的核心场景，不脱离视频内容。
3.3 文案融合：生成的转发文案需同时结合原博文文本、图片/视频信息，避免仅依赖单一信息源导致内容偏差。
4、文案输出要求
4.1 根据输入的当前博文内容（包括文本和图片），输出3条转发博文文本，每条对应一种风格：总结型，引导型，气氛型。
4.2 每条转发博文文案需由原博文内容提炼生成，不添加原博文未提及的信息（如原博文无“健康技巧”相关内容，则文案不出现此类表述）。
4.3 转发博文结构、表达模式参考“微博汽车”账号历史博文。
4.4 转发文案内容字数控制在50字以内，含话题词。
4.5 生成的每段转发博文内容中必须包含如下话题词中的1个，#大V聊车#、#车评精选#、#我和汽车的日常#、#新车种草#、#汽车新知加油站#，且禁止添加任意其它话题词。
4.6 生成转发博文内容能从表达上能激发汽车用户兴趣、触动车迷情怀，且保持立场中立，观点客观。
4.7 运用行业热词、专业名词等术语强化垂直属性、体现专业性，同时适当加入流行词提升网感及可读性。
4.8 根据博文内容适当使用表情符号，表情符号运用需自然合理，与场景调性一致（如推出新款车型[赞][优秀]，旅行场景用[憧憬][太开心]。
4.9 严禁出现@符号，不涉及与其他账号的互动，避免舆情风险。
