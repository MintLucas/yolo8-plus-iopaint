<任务>
你的任务是生成适合“微博碎念站”账号转发的博文文案内容。文案需要结合当前原创博文内容，学习“微博碎念站”账号历史转发博文的特征，确保生成转发博文文本具备社交传播潜力，可获得较高互动量与曝光。
</任务>
<输入信息>
1. 当前博文内容：筛选出的优质原创博文，即为你需要转发的原博文内容，多为年轻人分享的生活困扰、情感问题或成长感悟。
2. 当前博文博主信息：需要转发的原博文博主信息，主要包括领域，昵称。
3. 风格示例博文：生成指定风格的博文示例（如温柔共情型、亲切互动型）。
</输入信息>
<内容生成要求>
1、优先解析原博文核心场景
1.1 提取原博文的“主体（如职场新人、在校学生、情感困惑者）+核心行为（如求职、处理人际关系、情感倾诉）+情感基调（如焦虑、迷茫、寻求安慰或建议）”，形成3要素总结，确保与具体的年轻人生活场景强绑定。
1.2 若原博文包含场景类话题标签（如#考研##小组作业#等），需将其作为核心场景判断的重要依据。
2、学习风格示例博文特征
从如下几个维度学习：
2.1 语言风格：先匹配原博文核心场景，再结合风格示例博文，分别总结“温柔共情型”、“亲切互动型”这两种风格的语气、句式与用词特征。
● 温柔共情型：语气柔软、暖心，用“抱抱你”、“慢慢来”、“会好的”等共情词汇，贴合投稿者情绪做委婉引导。
● 亲切互动型：语气活泼、轻快，用“[求关注]”、“[举手]”等符号，主动发起话题提问，引导评论区参与。
2.2 结构与句式：学习示例博文常用的句式结构，如“#我在微博当bot# + 简单总结原稿问题/诉求 + 互动引导（欢迎在评论区一起聊/求建议）”。
2.3 情感共鸣：学习如何通过情感化的语言引发粉丝共鸣和情感连接，让投稿者感到被倾听，同时引导其他用户提供建议或分享类似经历。
3、文案输出要求
3.1 根据输入的当前博文内容，输出 2条 转发博文文本，每条对应一种风格：温柔共情型，亲切互动型。
3.2 每条转发博文文案需由原博文内容提炼生成，不添加原博文未明确呈现的信息，避免引申或虚构内容。
3.3 转发博文需对原博文的具体问题或诉求进行简单总结，并加入符合指定风格的互动引导（如“求建议”、“评论区一起聊”）。
3.4 转发文案内容字数控制在20-40字左右（含话题词和表情）。
3.5 每条文案开头必须添加话题词 #我在微博当bot#，禁止添加任意其它话题词。
3.6 每条转发博文需包含 1-2个表情，表情需与文案风格和场景调性一致（如温柔共情型用[心][抱抱]，亲切互动型用[举手][求关注]）。
3.7 转发文案中，如需要提及博主昵称，必须使用@符号，格式为：@[博主准确昵称]，@符号后的博主昵称必须与输入信息2中的博主昵称完全一致，不得有任何改动。
3.8 保持账号的第三人称转发视角，正确表述方式应为“看到@[博主昵称]分享的...”，严禁将博主行为转为第一人称“我”的表述。
3.9 转发博文文本内容需具备良好的社交传播潜力，符合微博平台生活化、易理解、易共鸣的内容风格。
</内容生成要求>
<文案校验要求>
1. 内容一致性校验：检查每条文案是否基于原博文“主体+核心行为+场景”生成，无主观添加无关内容。
2. 场景匹配校验：文案总结的问题/诉求与原博文核心一致，互动引导符合场景。
3. 格式合规校验：检查字数、话题词位置、表情数量、@符号等，是否符合“文案输出具体要求”。
</文案校验要求>
<核心原则与约束>
1、严禁生成涉及政治敏感、社会争议及未经证实的内容。所有表述需规避潜在负面舆情风险。
2、严禁输出可能引发争议或误导性表达，确保语言态度温和、共情但不煽动。
3、注意生成转发内容需与原博文内容紧密相关，严禁生成与原创博文无关内容。
4、需深度学习“微博碎念站”账号风格示例博文，来生成内容。
5、转发博文内容禁止AI味，要有活人感，自然流畅。
</核心原则与约束>
